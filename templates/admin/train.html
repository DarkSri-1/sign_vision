Pretrained model (ASL.h5 / .keras)

If you use the Kaggle notebook input ASL.h5 (American Sign Language dataset, ~4 MB), download it and upload it here. The app reads the model’s input size and channels automatically. Many notebooks add Rescaling(1/255) inside the network — the app now detects that and feeds 0–255 pixels instead of double-normalizing (which caused wrong predictions). For correct letter names, paste class labels below (one per line) in the same order as the notebook’s training labels—usually alphabetical folder order from the ASL alphabet dataset.

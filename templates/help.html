Help & documentation

Setup, roles, recognition, pretrained models, and fixes for common issues.

Quick start
  1. Install dependencies — From the project folder: pip install -r requirements.txt
  2. Run the app — python run.py then open http://127.0.0.1:5000
  3. Optional demo data — python seed_db.py --force creates sample users (see README for default admin password).
  4. Register your own account or sign in with a seeded user.
  5. Admins see an Admin link after login — manage dataset, training, and users there.
User workspace (signed-in)
  • Overview — Totals, model status, recent activity, shortcuts.
  • Live recognition — Start camera (grant permission), or upload an image. Uploads are saved with each history row for review.
  • History — Filter, export CSV/PDF, open a record to see metadata and image (for uploads), add personal notes, delete.
  • Accuracy — Metrics from last local training; if only a pretrained model is used, some charts may be limited until you train locally.
  • Profile — Update name, username, password.
Administrator
  • Users — Create, view, edit, activate/deactivate, delete (with safeguards for the last admin).
  • Dataset — Create class folders, bulk upload images, rename or delete a class, browse and delete single files.
  • Train & models — Train sign_model.keras on data/dataset/, or upload pretrained ASL.h5 / .keras with optional class labels (one per line, softmax order).
  • Recognition log — All users’ predictions; filter, open detail (including upload image), edit notes, bulk delete.
  • Debug logs — Technical prediction logs; filter by user, delete rows, or clear all.
Supported signs & labels

Training uses folder names under data/dataset/ as class labels. The recognition page lists the classes your active model expects.

For common Kaggle 29-class ASL checkpoints, use labels in the usual A–Z + del, nothing, space order if the admin upload form asks for them.

Where data lives
Application DB
SQLite file (path depends on your config) — users, sessions metadata, recognition history rows, prediction debug logs.
Training images
Folder per class under data/dataset/<class_name>/. Admin can upload, rename classes, or delete.
Trained model
Default output sign_model.keras (or path in config) after training; optional pretrained file e.g. ASL.h5 uploaded in Admin.
History uploads
When you predict from a file, a copy may be stored under instance/history_uploads/ and linked from history detail.
Frequently asked questions
Do I need an internet connection?
After installing Python packages, recognition runs locally. The UI loads fonts and Bootstrap from CDNs — for fully offline use, vendor those assets.
Can I use my own Kaggle or Colab model?
Yes. Export as Keras .h5 or .keras, upload in Admin → Train, and paste class labels in softmax order if they differ from your local dataset.
Why does the UI show the wrong letter?
The network outputs class indices. If the label list does not match the checkpoint (e.g. 29-class ASL order), mapping will be wrong — update labels or retrain with matching folders.
Is this production-ready for accessibility?
SignVision is aimed at learning and demos. Real-world accessibility systems need broader sign coverage, signer diversity, and rigorous evaluation.
Camera & accuracy tips
  • Use good lighting and a plain background; center the sign in the frame (default mode uses a center crop similar to many datasets).
  • If the app is configured for MediaPipe hand crop only when an env variable is set, follow README — mismatch with training hurts accuracy.
  • Wrong class label order for a pretrained file will show wrong letters even if the network is correct — fix labels in Admin → Train.
  • Training on CPU with huge datasets can take a long time; reduce epochs for a quick test.
Troubleshooting
Pretrained ASL.h5: nonsensical or wrong classes
Common cause was double normalization (app divided by 255 while the model also has Rescaling(1/255)). Re-upload the file in Admin → Train so scaling is saved as 0_255 when detected, or choose Force 0–255. Also paste class labels in correct softmax order (29 lines: A–Z, del, nothing, space).
No model / errors on predict
Train in Admin or upload a valid pretrained file; restart the server after config changes.
Camera blocked
Check browser permissions; some browsers need HTTPS for camera on non-localhost hosts.
Database / columns
The app upgrades SQLite with new columns on startup. If you use a copied old DB and see errors, check the console or recreate the DB from README.

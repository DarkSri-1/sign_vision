Platform at a glance

Inference

TensorFlow/Keras models (.keras / .h5), dynamic input size, softmax → class names from training or admin label list.

Inputs

Live webcam frames and image uploads; preprocessing matches model channels (grayscale/RGB) and resolution.

Accounts

Role-based access: standard users get workspace and history; admins additionally manage dataset, training, and global logs.

Storage

SQLite for users and recognition history; dataset under data/dataset/; optional history image copies under instance/.

Typical workflow

  1. Install — Python 3.10+, pip install -r requirements.txt, run python run.py.
  2. Optional seed — python seed_db.py for demo users and sample data.
  3. Admin — Add dataset classes/images or upload a pretrained model; train if needed.
  4. User — Sign in, open Recognition, use camera or upload; review History and exports.

Requirements & privacy

  • Webcam access in a modern browser (Chrome, Edge, Firefox).
  • GPU optional; CPU training can be slow on large datasets.
  • No data is sent to external recognition APIs — models run locally.
  • Suitable for academic presentation and offline evaluation.
